**Acknowledgement rates.** For the concurrent ext4 fixture, total logical bytes divided by wall time from the first WRITE yielded **261.2 MB/s through the last WRITE response**, **183.5 MB/s through the last file fsync**, and **131.6 MB/s through observation of complete destination drain**. The last interval includes metrics sampling. In the separate sequential reserve-held case the six fsyncs ranged from 42.3 to 380.9 ms, median 55.9 ms. Single initiator observations were 14.439 ms for FUA WRITE, 13.490 ms for the ordinary WRITE and 0.323 ms for its FLUSH. The patched target also fsyncs ordinary writes. These results cover the synthetic Linux paths. Physical 10GbE ingress, P3 endurance and two-HDD sustained destage remain app trial measurements.

**Physical storage accounting.** At the observed paced boundary, journal blobs allocated 501,673,984 B, journal.redb 114,688 B, raw-parts clean cache 482,979,840 B, decoded clean cache zero, catalog 57,344 B and metadata authority 45,056 B. After settlement the clean cache still held 740,777,984 B and journal.redb held 102,400 B. The receipt also contains apparent file sizes and both member allocations. Each clean cache store has a 1 GiB geometry floor. Include both stores, the journal admission envelope and its free reserve, filesystem overhead, and separately budgeted authority/catalog/state in physical sizing. The physical ZFS cache dataset previously used 786,132,992 B at a 0.064 GB configured scalar. [Native allocation samples](pressure.json)

**Finite memory.** The 9P fixture cgroups included their clients, engine, file cache and tmpfs member ballast. Their peaks were 1,424,732,160 B for replay, 2,332,876,800 B for pressure and 1,379,737,600 B for the ext4 run. Each had an 8 GiB ceiling, zero swap, two CPUs and zero OOM events. The separate authenticated NVMe run put the engine, FUSE client, target and initiator in the same 8 GiB/zero-swap cgroup pinned to CPUs 0–1. Its peak was 1,099,005,952 B. Aggregate SMB/NFS/NVMe package admission and physical ARC headroom require their own qualification. [9P cgroups](native.json) · [NVMe cgroup](../../../../scripts/nas-journal-nvme/merged/cgroup.json)
